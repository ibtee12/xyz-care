Project Overview

Matrix Math Care is a comprehensive, multi-role online coaching platform built to digitise the operations of a mathematics coaching centre. It enables administrators to manage the entire institution, teachers to deliver content and interact with students, and students to learn, track progress, and communicate — all within a single integrated web application.

The platform is fully responsive, works on desktop and mobile browsers, and is deployed on modern cloud infrastructure (Supabase for database and storage, Vercel-compatible Next.js build).

🎯

Project Goal: Replace manual/paper-based coaching centre operations with a robust digital platform covering enrollment, lesson delivery, live classes, quizzes, marks, payments, certificates, and real-time communication.

Key Highlights

🏫

Multi-Role Platform

Separate portals for Admin, Teacher, and Student — each with tailored dashboards and feature sets.

📹

Live Class System

Timed join-window for Zoom/Meet classes. Students can only access the link during the allowed window.

💬

Real-Time Chat

Direct messaging between students and teachers with image attachment support.

📊

Analytics & Reports

Admin dashboard with revenue tracking, enrollment charts, top courses, and quiz statistics.

🎓

Digital Certificates

Admin can issue completion certificates to students, visible in their personal portal.

🧠

Quiz Engine

Admin-built MCQ quizzes with auto-scoring, time limits, and per-attempt result tracking.

User Roles & Access Control

The platform has three distinct roles. Access control is enforced at two layers: Next.js Middleware (route-level redirect before rendering) and API route guards (session check on every endpoint).

🛡️ Admin

Full platform control. Manages all users, courses, and system settings.

  • Create / edit / delete courses (online & offline)
  • Manage student and teacher accounts
  • Issue certificates, manage payments and coupon codes
  • Build quizzes and manage marks/exams
  • Send notifications (in-app, email, SMS)
  • View analytics and revenue reports
  • Write and publish blog posts

👨‍🏫 Teacher

Manages their own courses and communicates with enrolled students.

  • Upload recorded video lessons (URL or direct upload to Supabase)
  • Schedule live classes with timed join windows and meet links
  • View enrolled students and their progress
  • Chat with students (text + image attachments)
  • View and manage marks for their courses
  • Receive in-app notifications

🎓 Student

Accesses their enrolled courses and tracks learning progress.

  • Browse and view enrolled courses (online lessons + live classes)
  • Watch video lessons; mark lessons complete to track progress
  • Join live classes during the active join window only
  • Take quizzes and view scored results
  • View marks, certificates, and payment history
  • Chat with teachers (text + image), participate in forums
  • Bookmark lessons, receive notifications

Feature Modules — Admin Portal

Dashboard

Landing page showing key platform metrics: total students, teachers, courses, enrollments, revenue, and recent activity. Provides quick navigation to all management sections.

Student Management

Full CRUD for student accounts. Features include:

  • Search by name, email, or roll number
  • Filter by class level and institution
  • View individual student profile (enrollments, marks, payments)
  • Auto-generated MatrixID (M-XXXX format) on registration

Course Management

Create and manage both online and offline courses:

  • Online courses: lessons, video content, live classes, quizzes
  • Offline courses: venue, batch, schedule information
  • Set price, thumbnail, description, and publish/draft status
  • View enrolled students per course

Marks & Exams

Upload exam marks via CSV, view score sheets per exam, and manage student performance records.

Quiz Builder

Create MCQ quizzes linked to courses with per-question marks, time limits, and optional descriptions. Quizzes are published and available to enrolled students immediately.

Payments

Track all student payments with status (paid/pending/failed), transaction IDs, payment method, and notes. View revenue summary.

Notifications

Send targeted notifications to all students or a specific roll number via three channels: in-app website alert, email (Resend), and SMS (Twilio).

Certificates

Issue digital completion certificates to students for specific courses, with auto-generated certificate numbers.

Coupons

Create percentage or fixed-amount discount coupons with optional expiry dates and usage limits.

Blog

Write and publish blog posts visible on the public-facing website. Rich text content with publish/draft management.

Reports & Analytics

Visual analytics dashboard with:

  • Monthly enrollment bar chart (last 6 months)
  • Top courses by enrollment count
  • Recent payments list
  • Quiz attempt count and certificates issued summary

Feature Modules — Teacher Portal

Dashboard

Overview of the teacher's courses, total enrolled students, and quick access to upload content or schedule live classes.

Course & Lesson Management

Teachers can upload recorded video lessons for their courses:

  • Paste a YouTube or Google Drive URL (embedded player auto-detects format)
  • Direct file upload (stored in Supabase Storage, publicly accessible URL)
  • Set lesson title, description, order number, and duration
  • Enrolled students receive an automatic notification on upload

Live Classes

The live class system is the most interactive feature for teachers:

  • Schedule a class with a Zoom or Google Meet link
  • Set the exact start time (datetime picker)
  • Set a "last check-in" window in minutes (e.g. 30 min) — students can only join within this window
  • After window closes, the link is completely hidden from students
  • All enrolled students receive an automatic notification with the class time
  • Teacher dashboard shows: Live Now / Upcoming / Ended sections with pulsing live badge
⏱️

Join Window Logic: If a class starts at 1:00 PM with a 30-min window, students can access the link from 1:00 PM to 1:30 PM. After 1:30 PM the button shows "Ended" and the link is hidden permanently.

Student List

View all students enrolled in the teacher's courses with their profile details.

Marks

View marks/scores for students across the teacher's courses.

Chat

Messaging interface showing all students enrolled in the teacher's courses:

  • Conversations sorted by most recent message first
  • Timestamps shown in sidebar (time/Yesterday/day name)
  • Image attachment support — teacher can send pictures
  • Full message history per student thread

Notifications

View in-app notifications sent by admin or system events.

Authentication & Security

Authentication Flow

1
User enters email + password
→
2
bcrypt.compare() checks hash
→
3
NextAuth issues JWT with role
→
4
Redirected to role dashboard

Security Measures

  • Passwords hashed with bcrypt (10 salt rounds) — never stored in plain text
  • JWT tokens signed with a secret key (NEXTAUTH_SECRET)
  • Middleware checks session role before rendering any protected page
  • Every API route independently verifies session role (defense in depth)
  • UUID validation on dynamic routes prevents Prisma injection via invalid IDs
  • File uploads restricted by MIME type (images: image/*, videos: video/*)
  • Supabase service role key server-side only — never exposed to client
  • Teacher access scoped: teachers can only see/modify their own courses and students

Registration

Students register with name, email, password, phone, class level, and institution. The system auto-generates a unique MatrixID (format: M-XXXX) by finding the highest existing number and incrementing it. The MatrixID is displayed in a modal on successful registration.

The student video player automatically detects the URL type and renders the appropriate player:

  • Google Drive URL → Drive preview iframe

Notification System

The platform has a multi-channel notification system. All in-app notifications are stored in the Notification table and shown in the student/teacher portals.

Automatic Triggers

  • New video lesson uploaded → all enrolled students notified
  • Live class scheduled → all enrolled students notified

Admin-Sent

  • In-app website notification
  • Email via Resend
  • SMS via Twilio
  • Target: all students or specific roll number

Notification Bell

  • Red badge shows unread count in sidebar
  • Polls every 30 seconds for new notifications
  • Instantly resets to 0 when student visits Notifications page
  • Uses a custom DOM event (notifications-read) for immediate badge refresh

Live Class System

The live class system is designed to function like a timed attendance system — students can only access the class link during an approved window, preventing late joins after the class has progressed.

Teacher Workflow

1. Create a Live Class

Select course, add title, paste Zoom/Meet link, set start datetime and join window (minutes).

2. Preview Timeline

Form shows exact open and close times before saving (e.g. "Join opens: 1:00 PM · Closes: 1:30 PM").

3. Students Notified

All enrolled students receive an automatic in-app notification with the class time.

4. Monitor Status

Teacher dashboard shows Live Now (pulsing green) / Upcoming / Ended sections in real time.

Student Experience

Before Start

Student sees "Not Started" with a live countdown: "Starts in 1h 45m".

During Window

Green "Join Now" button appears. Clicking opens the meet link in a new tab. Countdown shows time remaining: "Join closes in 18m 40s".

After Window

Button becomes "Ended" (grey, disabled). The meet link is permanently hidden — no way to retrieve it.

✅

Real-time: The student page uses a client-side interval (1 second tick) to update the status and countdown without any page refresh. The transition from "Not Started" → "Join Now" → "Ended" happens automatically in the browser.
