# Matrix Math Care (xyz-care)

Full-stack educational coaching platform built with Next.js 16, TypeScript, Prisma, and PostgreSQL.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Synchronize database:
   ```bash
   npx prisma db push
   npx tsx prisma/seed.ts
   ```

3. Run locally:
   ```bash
   npm run dev
   ```

## Production Build

```bash
npm run build
```
